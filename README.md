# Semantic Image Search

An AI-powered semantic image search app built with Next.js and Azure OpenAI.

## Project Description

Semantic Image Search enables users to find images using natural language queries. The app generates metadata and vector embeddings for images, storing them in a vector database for semantic search. Users can upload images, generate new ones with AI, and search by meaning rather than keywords.

## Technology Used

- **Frontend**: Next.js 14 with App Router and React Server Components
- **AI Services**: Azure OpenAI GPT-4o for metadata generation, Azure OpenAI DALL-E 3 for image generation
- **Storage**: Vercel Blob for image storage
- **Database**: Vercel Postgres with pgvector for vector similarity search
- **UI Framework**: shadcn/ui with Tailwind CSS
- **ORM**: Drizzle ORM for database interactions
